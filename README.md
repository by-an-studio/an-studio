# An Studio

Sitio web de An Studio, construido con Next.js (App Router) y Sanity CMS.

## Desarrollo

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver el resultado.

## Stack

- Next.js (App Router, Turbopack)
- TypeScript
- Tailwind CSS
- next-intl (i18n)
- Sanity CMS

## Sanity Studio

El Studio embebido está disponible en `/studio`.
